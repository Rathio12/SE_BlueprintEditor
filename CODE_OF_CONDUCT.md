# Code of Conduct

![Contributor Covenant](https://img.shields.io/badge/based%20on-Contributor%20Covenant%202.1-46B4E6?style=flat-square&labelColor=0B151B)

</div>

## Our pledge

We want this project to be a friendly place for everyone who builds ships, runs servers or writes code —
regardless of experience, background or identity.

## Expected behaviour

- Be respectful and constructive, especially when reviewing code or reports.
- Assume good intent and ask before assuming.
- Keep discussions on topic.
- Credit other people's work, including mod authors.

## Unacceptable behaviour

- Harassment, insults, slurs or personal attacks.
- Publishing someone's private information.
- Spam, trolling or deliberately derailing discussions.
- Sharing pirated games or other people's paid content.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block repeat
offenders. Report problems privately to the maintainer via [GitHub](https://github.com/Rathio12), or through a
[private security advisory](https://github.com/Rathio12/SE_BlueprintEditor/security/advisories/new) if it is sensitive.
