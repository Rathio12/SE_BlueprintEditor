# Code of Conduct

## Our pledge

We want this project to be a friendly place for everyone who builds ships, runs servers or writes code,
regardless of experience, background or identity.

## Expected behaviour

* Be respectful and constructive, especially when reviewing code or reports.
* Assume good intent and ask before assuming.
* Keep discussions on topic.
* Credit other people's work, including mod authors.

## Unacceptable behaviour

* Harassment, insults, slurs or personal attacks.
* Publishing someone's private information.
* Spam, trolling or deliberately derailing discussions.
* Sharing pirated games or other people's paid content.

## Enforcement

Maintainers may edit or remove comments, issues and pull requests that break these rules, and may block
repeat offenders. Report problems privately to the maintainer via GitHub
(https://github.com/Rathio12) or through a private security advisory if it is sensitive.

This code of conduct is adapted from the spirit of the
[Contributor Covenant](https://www.contributor-covenant.org/), version 2.1.
